# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.
Older commits and deployment images should be updated before use.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
[hello@krishparajuli.com.np](mailto:hello@krishparajuli.com.np).
Include the affected URL or file, reproduction steps, and the potential impact.
Do not include passwords, access tokens, or other people's personal information.

Please avoid public issues containing exploit details until a fix is available.
Keep testing limited to your own local copy; do not disrupt the live website,
access other people's data, or test third-party services without permission.

Reports will be reviewed and fixes prioritized according to their impact.
