# Cyber-ops and 3D portfolio

The homepage now reflects the published cyber-ops design. Project cards, statistics, writeups,
certifications, education, and hacktivities use the existing Astro collections and data files.
Other routes and the shared SEO component remain in place.

## Build and integration

Run `npm ci` and `npm run build`. The build bundles `src/effects/index.js` into
`public/effects/bundle.js` and `src/effects/scene-entry.js` into `public/effects/scene.bundle.js`.
Three.js is pinned and self-hosted; no runtime CDN or external model requests are required.
`src/layouts/Base.astro` loads the effects only when its `cyber` prop is enabled by the homepage.
The scene loads lazily after boot, when visible and effects are enabled. Asset paths respect Astro's base URL.

Edit modules in `src/effects/`, styles in `public/effects/`, and homepage styling in `public/css/`.
Generated bundles are committed for direct asset serving and regenerated by the build.
The public portrait is resized and encoded as WebP to reduce its download size.

## Experience and tuning

- `boot.js`: once-per-session boot, any-key/click skip, short mobile timing.
- `rain.js`: density, frame rate, and pointer-reactive data rain.
- `scramble.js` and `glitch.js`: heading decrypt timing and intermittent glitch frequency.
- `terminal.js`: command input, history, autocomplete, and the Konami-code effect.
- `cursor.js`: crosshair and trail, disabled for touch input.
- `ambient.js` and `portrait.js`: scan, counters, circuit traces, and telemetry.
- `core.js`: shared scheduler, Full/Lite/Off preferences, and reduced-motion handling.
- `spatial.js`: card tilt, toolkit network, fracture duration, and particle count.
- `scene-entry.js`: camera distance, pixel-ratio ceilings, frame limits, and strike duration.
- `scorpion-model.js`: procedural anatomy and animation rig.
- `crt.css`: scanline and vignette intensity; colors derive from the existing CSS palette.

Each effect module exposes its tuning constants near the top. Footer controls persist the selected
quality and CRT setting. Off and reduced-motion modes retain the original static SVG badge.
The 3D model contains eight legs, two pincers, five tail joints, 98 meshes, and 23,528 triangles.
The renderer pauses offscreen and in hidden tabs and handles unavailable/lost WebGL contexts.
Full mode enables pointer tracking, tilt, particles, and a brief click-triggered screen fracture.
Lite reduces animation and disables the heavier interactions.

## Validation

Run `npm test`, `npm run test:3d`, `npm run typecheck`, `npm run check:links`, and `npm run lint`.
After building, run `npm run deploy:prepare` followed by `npm run test:portability`.
The geometry test checks anatomy, bounds, finite projections, and rendering budgets.

The earlier published version was checked for keyboard boot skip, terminal commands, navigation,
mobile overflow, and effect-mode behavior. The available browser disables WebGL, so its SVG fallback
was tested and the model was inspected independently through geometry projection.
Actual GPU appearance, physical-phone frame rate, and a Lighthouse score above 85 remain unverified.
